# CCNA Networking Practicals

Welcome to my networking practicals repository.

This repository documents my hands-on learning and practical exercises in computer networking as I develop my skills towards the Cisco Certified Network Associate (CCNA) certification.

## About This Repository

Here, I document networking concepts, Cisco Packet Tracer simulations, network configurations, troubleshooting exercises, and lessons from my classroom practicals.

The goal is to build a structured record of my technical development and demonstrate my understanding of networking concepts through practical implementation.

## Topics Covered

- Network Fundamentals
- OSI and TCP/IP Models
- IP Addressing and Subnetting
- VLAN Configuration
- Inter-VLAN Routing
- Static Routing
- Spanning Tree Protocol (STP)
- PortFast
- EtherChannel
- Network Troubleshooting

*Additional topics will be added as I progress through my training.*
